## 2. 抓取方式与核验

- 法律、行政法规、部门规章正文来自人社部相应栏目页面，抓取为 Markdown 并保留来源 URL、发布时间与 SHA-256。
- 部门规章页面普遍附带官方 DOCX 与 PDF 原件，已一并归档到 `regions/national/regulations/files/`（共 20 份原件：PDF 9、DOCX 7、DOC 4）。
- 司法解释采用最高人民法院公报版本（含法释文号与施行日期）。
- 人社部网站启用了 EO_Bot 反爬挑战（返回一段设置 Cookie 的脚本），抓取脚本按公开挑战逻辑设置 `__tst_status` / `EO_Bot_Ssid` Cookie 后正常访问；不绕过任何登录或访问控制。

## 4. 后续可补充

1. 与劳动仲裁计算相关但尚未归档的规范：社会保险法配套的《实施〈中华人民共和国社会保险法〉若干规定》、《工伤认定办法》、《非法用工单位伤亡人员一次性赔偿办法》、《企业职工患病或非因工负伤医疗期规定》。
2. 全国人大或国务院公报中的法律修正案文本，用于标注历次修订沿革。
3. 其他部门规章（如《劳动人事争议仲裁委员会办案规则》历史版本），需要时以 `superseded` 状态保留旧版本。
4. 最高法及各地法院的劳动争议典型案例、会议纪要（属裁判口径，另行评估归档方式）。

## 5. 重要说明

本索引仅记录官方公开来源与已归档资料，不构成法律意见；法律、行政法规可能被修正或废止，使用前请核对现行有效版本。
