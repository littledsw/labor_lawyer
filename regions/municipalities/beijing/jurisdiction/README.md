# 管辖规定

## 目标

归档劳动人事争议案件管辖规则、调整通知和区县办事分工说明。

## 官方入口

- 北京市劳动人事争议调解仲裁网上服务平台
  - https://fuwu.rsj.beijing.gov.cn/zhrs/api4/arbitration/html/home/index

- 北京市政府公开页：关于调整劳动人事争议仲裁案件管辖的通知
  - https://www.beijing.gov.cn/zhengce/gfxwj/202207/t20220714_2771636.html

- 东城区政务服务中心仲裁指南（含相关规定说明）
  - https://zwfw.beijing.gov.cn/art/2022/2/20/art_3077_341211.html

## 资料清单（待逐项归档）

- 管辖调整通知
- 劳动人事争议仲裁受理范围
- 区县仲裁管辖说明
- 相关政策解读

## 备注

其中以北京政府公开页和区级政务服务页为主，需保留原始法定依据与较新版本通知内容。
